# Code of conduct

BaSyx Studio is an Eclipse Foundation project. Everyone who takes part in it, in
issues, discussions, pull requests or any other project space, follows the
[Eclipse Foundation Community Code of Conduct](https://www.eclipse.org/org/documents/Community_Code_of_Conduct.php).

Report unacceptable behaviour to the Eclipse Foundation at
<conduct@eclipse-foundation.org>. Reports are handled confidentially, as the
code of conduct describes.
